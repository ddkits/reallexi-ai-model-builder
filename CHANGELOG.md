## 1.4.28 — 2026-11-24

- Enterprise Learning Studio can download and import versioned JSON prompt packs. A pack can mix ordinary requests, verifiable reasoning summaries, coding tasks and recorded tool calls and results.
- Reviewed examples can extend a compatible Studio dataset. The result is a new trainable version with the original and newly accepted rows.
- Enterprise Admins can select a server-configured online Chat Completions teacher for text and supported image requests. The Studio asks before sending session inputs to the configured provider.
